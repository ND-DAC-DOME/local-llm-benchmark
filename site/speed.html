Speed

How fast each setup answers, and why

Decode speed is tokens generated per second for one request on an otherwise idle server; prefill is how fast the prompt is read before the first token. Both measured by the same script on every server, with unique prompts so caches cannot inflate them.

Speculative decoding speeds up without changing answers

Qwen3.8 + MTP: 31.8 → 50.8 tok/s. Muse + DFlash: 38.5 → 56.5 tok/s.

The A6000 decodes 2.5× faster than the Spark; prefill is about equal

Same checkpoint, same vLLM recipe, MTP on both: 50.8 vs 20.3 tok/s.
