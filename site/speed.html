Speed

How fast each setup answers, and why

Decode speed is tokens generated per second for one request on an otherwise idle server; prefill is how fast the prompt is read before the first token. Both measured by the same script on every server, with unique prompts so caches cannot inflate them.

MTP acceptance and the reduced draft vocabulary

The image's drafter proposes 2 tokens per step from a fixed set of 65,536 token ids; the model verifies every proposal against its full output head, so answers are unchanged and only acceptance can drop. How much does the reduced vocabulary cost? We re-tokenized every saved reasoning trace and answer of this study with the Flash-Next tokenizer and counted the tokens outside the set (method):

The set is essentially ids 0–65,535 (BPE merge order), so what falls out are line-start variants that reasoning uses (" Hmm", "Potential", "Proceed", "Probably") and chemistry pieces (" methyl", " benz"); 6,666 distinct ids are ever missed, the top 40 are 27% of misses. Ceiling on the effect: about 1.6 points of acceptance on this text. A list built from reasoning traces would recover it; not tested on the server (needs a restart with a new list).
